# 01 - Temeller

Python'a ilk adım: temel sözdizimi, veri tipleri ve program akışı.

## Konular

- Değişkenler ve veri tipleri (`str`, `int`, `float`, `bool`, `None`, `complex`)
- Operatörler (`/`, `//`, `%`, `**`, zincirleme karşılaştırma, `in`, `is`)
- Stringler, dilimleme ve f-string ile biçimlendirme
- Koşullar: `if/elif/else`, üçlü ifade, `match-case`
- Döngüler: `for`, `while`, `enumerate`, `break`, `continue`, `for-else`
- Tip dönüşümü ve `try/except/finally` ile hata yakalama

## Çalıştırma

```bash
cd 01-temeller
python temeller.py          # konu anlatımı
python alistirmalar.py      # alıştırma çözümleri (assert ile doğrulanır)
```

## Dosyalar

| Dosya | Açıklama |
|-------|----------|
| `temeller.py` | Altı bölümlük konu anlatımı ve örnek çıktılar |
| `alistirmalar.py` | BMI, FizzBuzz, basamak toplamı, palindrom, çarpım tablosu, artık yıl alıştırmaları ve çözümleri |
