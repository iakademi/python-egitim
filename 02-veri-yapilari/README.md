# 02 - Veri Yapıları

Python'un yerleşik koleksiyon türleri ve `collections` modülü.

## Konular

- Liste (`list`): ekleme, silme, dilimleme, sıralama
- Demet (`tuple`) ve `namedtuple`
- Sözlük (`dict`): `get`, `items`, `Counter`, `defaultdict`
- Küme (`set`): kesişim, birleşim, fark
- Liste / sözlük / küme comprehension
- `sorted` ve `key` ile çok ölçütlü sıralama
- `deque` ile kuyruk işlemleri
- Sığ (`copy`) ve derin (`deepcopy`) kopyalama farkı

## Çalıştırma

```bash
cd 02-veri-yapilari
python veri_yapilari.py
python alistirmalar.py
```

## Dosyalar

| Dosya | Açıklama |
|-------|----------|
| `veri_yapilari.py` | Konu anlatımı |
| `alistirmalar.py` | Tekrarsız sıralama, anagram, kelime sıklığı, iki toplam, matris toplamı, gruplama alıştırmaları ve çözümleri |
