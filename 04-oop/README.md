# 04 - Nesne Yönelimli Programlama

Python'da sınıflar ve nesne yönelimli tasarım.

## Konular

- Sınıf, `__init__`, örnek ve sınıf değişkenleri
- `property` ile kapsülleme (getter/setter)
- Kalıtım, `super()`, soyut sınıflar (`ABC`, `abstractmethod`) ve polimorfizm
- Özel metotlar: `__str__`, `__repr__`, `__add__`, `__eq__`, `__len__`, `__iter__`
- `@classmethod` ve `@staticmethod`
- `dataclass` ile veri sınıfları
- Kompozisyon (has-a) ilişkisi

## Çalıştırma

```bash
cd 04-oop
python oop.py
python alistirmalar.py
```

## Dosyalar

| Dosya | Açıklama |
|-------|----------|
| `oop.py` | Konu anlatımı |
